# Password Strength Checker

A simple Python-based Password Strength Checker that analyzes the strength of a password.

## Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Classifies passwords as:
  - Weak
  - Medium
  - Strong

## Technologies Used

- Python
- Regular Expressions (re module)

## Run

```bash
python password_checker.py
```

## Example

Input:
```
Hello@123
```

Output:
```
Password Analysis
------------------------------
Length: 9
Strength: STRONG

Checks:
✓ Minimum 8 Characters
✓ Uppercase Letter
✓ Lowercase Letter
✓ Number
✓ Special Character
```
